# Elektrik — приватний пошук роботи та навчання

Незалежний застосунок у цій папці. Старий `wtbackend-go` використано лише як приклад архітектури адаптерів; він не потрібен для запуску. Жодних платежів, підписок або публічної реєстрації.

## Запуск

Потрібен Node.js 24+. База SQLite вбудована в Node; у Node 24 можливе попередження experimental.

```powershell
npm ci
npm run build
npm start
```

Сайт: http://127.0.0.1:4317. Для розробки — `npm run dev` (React: 5173; API: 4317). Запускай лише один сервер бота одночасно. У `.env.local` вже можуть бути приватні налаштування: не перезаписуй їх. Для нового середовища скопіюй `.env.example` і внеси свої значення.

`npm run collect` запускає окремий збір. Не запускай його паралельно із серверним збором. `npm test` перевіряє класифікацію, парсери, фільтри, дедуплікацію, приватний доступ та команди бота без надсилання реальних повідомлень.

## Telegram

- `BOTTOKEN` — токен BotFather, лише на сервері.
- `TELEGRAM_OWNER_IDS` — дозволені числові ID через кому. Без цього бот не запускається. Працює лише в особистих чатах власників.
- `BOT_ENABLED=true` — запуск long polling. HTTPS webhook не потрібен. Наявний webhook не видаляється автоматично.
- `/start`, `/search Elektriker`, `/filters`, `/location Berlin`, `/location unknown`, `/location all`, `/saved`, `/refresh`, `/status`, `/reset`.
- Фільтри й позиція Telegram updates зберігаються в SQLite. Обране спільне для сайту та дозволених власників; це особистий інструмент, не багатокористувацька платформа.
- Фоновий збір працює кожні 120 хвилин, поки процес запущений. Немає автоматичних розсилок: бот відповідає на запити власника.

## Пошук

15 форматів можливостей, 15 напрямів і понад 60 німецьких назв/синонімів. Довідник і посилання на першоджерела доступні на вкладці «Довідник».

Місце: місто/поштовий індекс (текстовий фільтр), окремо «місце не вказано». Георадіус поки не реалізований. Онлайн/офлайн/гібрид та довгі/епізодичні/відсутні поїздки — незалежні фільтри. Відсутність даних означає `unknown`, не «офлайн» і не «без поїздок».

Автоматичні джерела:

- Bundesagentur für Arbeit: перевірений v6 endpoint, 24 запити за професіями × робота/Ausbildung/практика, сторінки та паузи. За замовчуванням 2 сторінки по 50 на запит. Наступні запуски чергують найновіші та глибші сторінки, до 40-ї сторінки. Це обмежене, поступове охоплення, а не гарантія всіх вакансій.
- Arbeitnow: перші 3 сторінки API, відбір релевантних назв.
- WBS TRAINING: сторінки електротехніки, автоматизації та SPS → конкретні курси. Позначаються як каталожні: дата початку, ціна, доступність та фізичний навчальний центр не вгадуються.

mein NOW, Siemens SITRAIN, IHK/HWK, Hochschulkompass, TÜV, Anerkennung — перевірені напрями подальшого пошуку, з прямими переходами. Вони **не позначені як автоматичні імпортери**. LinkedIn, Indeed, StepStone, Telegram-канали не парсяться цим релізом. Обхід CAPTCHA та логінів відсутній.

Помилки/часткові відповіді відображаються на вкладці «Джерела». Існуючі результати не видаляються при збої джерела. `lastSeen` — час останнього спостереження, не підтвердження, що вакансія досі відкрита. Повні описи BA доступні у першоджерелі; автоматичне визначення поїздок з їхніх повних текстів не виконується.

## Приватне розміщення / Coolify

`compose.yaml` — production-стек, `compose.local.yaml` додає локальний порт. Змінні передаються через Coolify або `docker compose --env-file .env.local -f compose.yaml -f compose.local.yaml up -d --build`. Перед локальним Docker-запуском установи `WEB_PASSWORD` (мінімум 6 символів). За reverse proxy використовується production Compose без локального override. Docker healthcheck перевіряє внутрішній порт 4317; зовнішні порти production-стек не публікує.

Готовий Dockerfile, healthcheck `/api/health`, постійний volume `/app/runtime`. Зовнішнє розміщення потребує окремого домену/ресурсу: цей проєкт не додається до WTBackend.

1. Створи окремий сервіс із цим Dockerfile, порт 4317.
2. Передай `BOTTOKEN`, `TELEGRAM_OWNER_IDS`, `BOT_ENABLED=true` через secrets/env.
3. Встанови довгий випадковий `WEB_PASSWORD` (мінімум 6 символів), `HOST=0.0.0.0`, `PUBLIC_URL=https://твій-домен`, `COOKIE_SECURE=true` за HTTPS reverse proxy.
4. Підключи постійний volume `/app/runtime`. Не включай `.env.local` у Docker image або Git.
5. Зупини локальний бот, перш ніж запускати серверний, щоб уникнути Telegram 409 Conflict.
6. Перевір health, вхід на сайт, `/start` з дозволеного ID та журнал збору.

Без `WEB_PASSWORD` API допускає лише прямі loopback-запити з локальним Host. Для мережевого bind із паролем коротшим за 6 символів запуск відхиляється. Сесії HttpOnly/SameSite, пароль порівнюється за хешем у сталий час, є обмеження спроб входу та перевірка Origin. HTTPS забезпечує reverse proxy. Закладки та історія — локальні в SQLite; резервуй весь volume штатним SQLite backup або під час зупинки сервісу.

## Структура

- `shared/catalog.ts` — досліджені назви, класифікації, першоджерела.
- `server/sources.ts` — незалежні адаптери.
- `server/classify.ts` — нормалізація й класифікація.
- `server/store.ts` — SQLite, дедуплікація, закладки, журнали.
- `server/bot.ts` — приватний Telegram.
- `src/` — React, телефонний інтерфейс, оригінальний React Bits AnimatedContent із реєстру; анімація вимкнена для reduced motion.

У `docs/research.uk.md` — пояснення термінів, видів можливостей і стратегії охоплення.
