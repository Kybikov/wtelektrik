# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

React and real React Bits components requested by the user. Independent service, informed by the Go JobBot adapter architecture in wtbackend-go. Backend implementation choice delegated through the request to build the complete project.

## Users

One private Ukrainian-speaking owner searching electrical work and education opportunities in Germany on a phone or Telegram.

## Product Purpose

Collect, classify, deduplicate and search opportunities, keeping original German titles and Ukrainian explanations.

## Capabilities and Constraints

All Germany, location filter, explicit unknown-location filter. Online/offline/hybrid independent of long travel requirements. Work, vocational education, retraining, courses, further education and adjacent opportunities. No payments, public signup or subscriptions. Private Telegram allowlist and private website access. Preserve the existing wtbackend-go repository and its parallel edits.

## Evidence on Hand

Existing JobBot adapter contracts and source architecture read as reference. BIBB and Bundesagentur occupational directories. Local .env.local contains bot credentials; never expose secrets. No fabricated listings. Source failures and unsupported sources must be visible.

## Open Decisions

Bot owner ID and hosting destination are pending. Elektryk is a provisional project name from the workspace, not a confirmed brand. Default UI language Ukrainian inferred from the request.
